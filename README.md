# MyMarkdown

一款 **Typora 风格**的所见即所得 Markdown 桌面编辑器，基于 Electron + Vite + TypeScript + Milkdown 构建，开箱即用，支持丰富的排版、代码块、表格、图片与主题定制能力。

## ✨ 功能特性

### 编辑体验
- 所见即所得编辑：标题（H1–H6）、粗体、斜体、删除线、列表、任务清单、引用、代码块、表格、链接、图片
- 排版增强：字号设置（支持选中文字局部调整）、首行缩进两字符、首字下沉、上标/下标、次方与数学书写
- 查找与替换：逐条高亮定位，自动滚动到可见区域
- 大纲/目录侧栏：快速跳转章节

### 代码块
- 语言标记下拉框，涵盖常见编程语言
- 关键字红色高亮，借鉴主流代码规范
- 相邻两行异色显示（斑马纹），行号标注
- 一键复制、一键清除，空代码块自动删除

### 表格
- 插入表格，支持合并单元格
- 横向/纵向斑马纹双色区分
- 单元格内容对齐（居中/左/右/上/下）
- 列宽与行高拖拽调整，调整结果持久化保留

### 图片
- 粘贴 / 拖入图片自动保存到当前文件夹，并插入 `![](...)` 引用（支持所有图片格式）
- 右键设置对齐方式：左对齐 / 右对齐 / 居中
- 背景图片支持透明度调节、渐变边缘、自适应窗口

### 文件管理
- 左侧文件树：打开文件夹、新建 / 重命名 / 删除、右键菜单
- 侧栏宽度自由拖拽，文件名过长自动省略号
- 双击 `.md` 文件直接打开

### 主题与个性化
- 浅色 / 深色主题，亮度可调
- 全 UI 主题定制：全局背景、编辑区、顶栏、代码块、表格等颜色均可自定义
- 背景图片：更换图片、调节透明度、左右渐变模糊
- 主题文件一键导入 / 导出，可分享给他人
- 内置深色紫金（EVA）等主题

### 设置与持久化
- 编辑区宽度占比（默认 90%）可调，可自定义
- 代码字体大小、代码块行号开关、斑马纹与表格双色自定义
- 自动保存间隔可配置
- 各项设置独立重置 / 全部重置

## 🚀 开发与构建

环境要求：Node.js 22+

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build
npm start

# 打包 Windows 安装包（输出到 release/ 目录）
npm run dist
```

## ⌨️ 快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+N | 新建文件 |
| Ctrl+O | 打开文件夹 |
| Ctrl+S | 保存 |
| Ctrl+Shift+T | 切换主题 |
