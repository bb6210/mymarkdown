# MyMarkdown

一款 Typora 风格的所见即所得 Markdown 桌面编辑器，基于 Electron + Vite + TypeScript + Milkdown。

## 功能特性

- 所见即所得编辑：标题、加粗、斜体/删除线、列表、任务清单、引用、代码块、表格、链接、图片
- 代码块增强：语言标签、行号、斑马纹配色、一键复制、一键清除
- 表格增强：合并单元格、行列拖拽调整、单元格对齐、斑马纹配色
- 图片：粘贴/拖入自动保存到当前文件夹并插入引用，右键设置对齐方式
- 左侧文件树：打开文件夹、新建/重命名/删除、右键菜单、宽度拖拽
- 大纲/目录侧栏、查找与替换
- 全文排版：标题 1-6 级、字号、首行缩进、首字下沉、上下标等
- 主题系统：亮色/深色主题、全 UI 主题定制、背景图片、主题导入/导出
- 社区：登录社区账号、一键发布主题到 MyMarkdown 社区、进入社区
- 自动保存、设置持久化

## 开发环境

需要 Node.js 22+。

```bash
npm install
npm run dev
```

## 构建与启动

```bash
npm run build
npm start
```

## 打包 Windows 安装包

```bash
npm run dist
```

产物位于 `release/` 目录。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+N | 新建文件 |
| Ctrl+O | 打开文件夹 |
| Ctrl+S | 保存 |
| Ctrl+Shift+T | 切换主题 |
